# Black Screen Online

A simple black screen website with a clock, custom text, and color options.

Hosted live at: https://blackx.netlify.app/

## Features

- **Clock**: Displays the time in the top-left corner. It is dimmed by default and becomes bright when you hover over it.
- **Focus Text**: Click the text (or the pencil button if empty) to type a custom label directly on the page. Press `Enter` or click outside to save; press `Escape` to cancel.
- **Colors**: Click the menu in the top-right to pick predefined colors or use the custom color picker.
- **Dimmed Controls**: Buttons are small and fade out when your mouse is not near them.
- **Fullscreen**: Toggle fullscreen by clicking the button or pressing `F`.
- **Auto-Save**: Remembers your custom text and background color when you refresh.

## How to Run

Simply open `index.html` in any browser, or host it locally:
```bash
python3 -m http.server 8080
```
